# BuyBloom – E-Commerce Backend API

BuyBloom is a Python Flask-based e-commerce application developed as part of a Python Programming Internship. It provides essential e-commerce functionality including user authentication, product management, shopping cart, order processing, search, categories, and REST API endpoints.

## Features

- User Registration
- User Login and Logout
- Product Listing
- Product Search
- Category Filtering
- Shopping Cart
- Add Products to Cart
- Remove Products from Cart
- Stock Management
- Place Orders
- Order History
- Order Status
- REST API for Products
- REST API for Categories
- SQLite Database
- Responsive Web Interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2
- REST API
- Gunicorn
